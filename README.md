# Порівняльна характеристика платних тарифних планів стримінгового сервісу Netflix.

## Мета проєкту

Навчальна вебсторінка для відпрацювання семантичної верстки таблиць (`caption`, `thead`, `tbody`, `th` із `scope`), базової нормалізації стилів, центрування контентного контейнера та підключення локальних шрифтів формату WOFF2 із системним fallback.

## Використані технології

- HTML5 (семантична розмітка таблиці)
- CSS3 (`@font-face`, `border-collapse`, псевдоклас `:nth-child`, базова нормалізація)
- Git та GitHub Pages

## Результат перевірки

Сторінку фактично перевірено у Google Chrome та Opera. Друге середовище [доступне, порівняння виконано у Firefox — відображення ідентичне / недоступне]. Локальний шрифт завантажується коректно, таблиця та контентний контейнер відображаються стабільно без горизонтального скролу.
