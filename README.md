# Порівняльна характеристика платних тарифних планів стримінгового сервісу Netflix.

## Мета проєкту

Навчальна вебсторінка для відпрацювання семантичної таблиці, базової нормалізації стилів, використання контентного контейнера та підключення локальних шрифтів формату WOFF2 із системним fallback.

## Використані технології

- HTML5 (семантична розмітка таблиці)
- CSS3 (`@font-face`, `border-collapse`)
- Git та GitHub Pages

## Результат перевірки

Сторінку фактично перевірено у Google Chrome та Opera. Інше середовище Safari. Локальний шрифт завантажується коректно, таблиця та контентний контейнер відображаються стабільно без горизонтального скролу.
